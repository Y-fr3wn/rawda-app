# تطبيق الروضة الإسلامي — الإصدار 1.4.3

هذا المستودع يحتوي على المصدر المحفوظ من مشروع الروضة 1.4.3 (Flutter/Android)، ويُستخدم لبناء نسخة اختبار عبر GitHub Actions.

## المصدر الأصلي
للتغلب على حدود نقل الملفات، قُسّمت حزمة المشروع المضغوطة إلى أجزاء نصية داخل مجلد source-parts.
يعيد مسار البناء تجميع الحزمة والتحقق من بصمة SHA-256 ثم فكّها واسترجاع ملفات الأذان المكررة. ملفات لقطات الاختبار مستبعدة من حزمة النقل فقط وليست مطلوبة للبناء.

بصمة SHA-256: ee84f3153a14e9dfe871e8dd206f130907c04046aea79c37b2b45bebb31120e4

## إنشاء ملف APK
افتح تبويب Actions ثم Build Rawda 1.4.3 Android، وافتح آخر تشغيل ناجح. ستجد Rawda-1.4.3-TEST-APK ضمن Artifacts.

ملف الاختبار بتوقيع مختلف، وقد لا يصلح كتحديث مباشر للتطبيق القديم. إصدار APK موقّع متوافق يحتاج أسرار مفتاح التوقيع الأصلي (RAWDA_KEYSTORE_BASE64 و RAWDA_KEYSTORE_PASSWORD).

ملاحظة: نجاح البناء لا يضمن عمل الأذان مع قفل الشاشة أو صحة مصادقة Firebase على هاتف حقيقي؛ يلزم اختبار ذلك قبل التوزيع.
